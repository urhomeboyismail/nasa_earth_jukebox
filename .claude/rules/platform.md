# Platform: phone and desktop

The app runs on phones and desktops, and can be installed from the browser (PWA manifest and icons, T120).

**Layout is deferred to the end.** The team lead does one layout pass on the finished app. Until then, don't check widths, don't rework layout for phone or desktop, and don't add layout checks to tickets or PR descriptions. Use the existing components and design tokens, so that pass stays small. `.claude/skills/responsive-layout/SKILL.md` stays as a reference for it.
