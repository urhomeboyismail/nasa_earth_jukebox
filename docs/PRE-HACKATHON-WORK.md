# What was built before and during the hackathon

For judges and the team. The 2026 NASA Space Apps Challenge started for this team on **9 Nov 2026**. Everything committed to this repository before that day is pre-hackathon work.

## How the work is split

**Before the hackathon (2 to 8 Nov 2026): a broad, data-agnostic design.** It's a general "Earth Jukebox" that turns any dated, colour-scaled map into sound and text. It wasn't tuned to any one NASA data set; it ran on a fixture and made-up (synthetic) data sets.

**During the hackathon (from 9 Nov 2026): refinement for each NASA data set.** Real NASA data sets are added and tuned one by one through their own data files (`docs/DATASET-PLAYBOOK.md`), plus the evidence, write-up and submission.

## Outside resources used

- **NASA data:** listed per data set in its `manifest.json` (`source`) and in `docs/data-sources.md`.
- **Libraries:** React, Vite, Tone.js, tonal, zod (front end); FastAPI and google-genai (server).
- **AI:** Google Gemini Live runs the optional voice guide. Coding assistants (Claude Code, Codex) helped write code and docs; the team reviewed every change.
- Planet intro (14 Nov, `feature/planet-intro`, on top of `feature/orbit-globe`): on a first visit a full-screen planet with Echo on top asks your name (typed, or said where the browser has speech recognition), then fades to Home (`src/features/intro/`; the name stays on this device).
- Interface sounds (14 Nov, AU-UI, `feature/AU-UI-interface-sounds`, PR #76): five more quiet cues behind the existing "Interface sounds" switch: playback starts and ends, Compare date A (one blip) and date B (two), and a successful link copy (`src/audio/cues.ts`).
- Tour from the welcome (14 Nov, JB09, `feature/JB09-tour-from-welcome`): finishing the welcome on "I can see the map" starts the guided tour, and when the tour finishes Echo flies back along a curve to the dock (Stop tour and Esc still end it at once; no flight under reduced motion).
- About: keyboard shortcuts and screen-reader help (14 Nov, UI11, `feature/UI11-about-keys`): two new cards on About. "Keyboard shortcuts" is a table of every keyboard row from the shared list in `src/interaction/shortcuts.ts`, so it matches the Listen dialog; "Using a screen reader" gives short steps for NVDA, JAWS, VoiceOver and TalkBack.
- Chat welcome (14 Nov, JB11, `feature/JB11-chat-welcome`): the welcome is a chat with Echo (name, four sound chips, then the path and sound check) ending with "Frequencies locked" in Echo's bubble, and a "Prefer manual setup?" form with the same choices. The name is the planet intro's (`earth-jukebox:intro`), asked only when the intro did not get it.
- Motion layer (14 Nov, UI05, `feature/UI05-motion-layer`, PR #86): press recoil, sliding drawers, path drawing, a sky backdrop, the Night/Day theme sweep and Echo's flight, all on CSS, the Web Animations API and `requestAnimationFrame` (no Anime.js) in `src/motion/`, behind one reduced-motion gate.
