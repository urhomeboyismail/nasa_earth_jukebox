# Parked ideas — not dead

TL;DR: Everything cut so far is parked here with the reason it was parked and what would bring it back. Nothing here was rejected for being a bad idea; most were parked on data or build-cost grounds that can change at the hackathon.
Rule going forward: a data finding alone never cuts an idea. Data is unknown until the event, so data-based reasons mark an idea "waiting on data".

## Waiting on data (revive when the event's frames/datasets are known)

| Idea | Why parked | Revive if |
| --- | --- | --- |
| Sea-level story | I found no verified data route | The event provides, or we find, a sea-level frame set or table |
| "45 years from 1979" drama | The GIBS layers I checked start 2000/2002 | Provided frames or an agreed cross-check series cover longer |
| Three gold stories (temperature, ice, ocean) | I checked only two layers | Provided data supports three, and the first works end to end |
| Coast duet (nearshore vs offshore voices) | Contrast in the data was never tested | A coast/offshore pair shows a measurable difference in the real data |
| Event mode / context pack (several datasets as an ensemble) | Needs several aligned datasets | Aligned datasets are provided; still at most two layers at once |
| Live mode for any EIC visualization | Reliability, and some pages are video-only | The event gives frame sets with colour bars, or a pre-tested shelf of 5–6 |
| Frame-literal column scan | Common (vOICe, Chandra scans) | Frames have a clean colour bar; keep as the sighted "frame drives sound" bar |
| Today's fires (daily VIIRS jukebox) | Frames need conversion | A live feed is useful for the demo |
