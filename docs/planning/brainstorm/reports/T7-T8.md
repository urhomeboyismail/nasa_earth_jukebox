# Report: T7 (sighted view) and T8 ("What the sound hides")

TL;DR: Both are built and tested. The picture, data table, hides section and listener log work in a real Chrome page with real clicks. Nobody has listened to the hides versions, no screen reader has read the new sections, and the "2 of 3" listener test has not been run.
Status: built, **not signed off**. By the T7+T8 fork, 2026-11-07.

## What was built

**T7: Picture section** (`app/player/picture.js`, section in `app/index.html`)
- Shows the current step's real GIBS frame (160×160, scaled, pixelated). Short alt text = `alt_short`; long description = `alt_long`, linked with `aria-describedby` and also shown as text.
- A dashed "Whole box" outline, `aria-hidden`. No point marker: each value is the average of the whole box, and the page says so.
- A rest step shows a hatched panel: "No map was published for this date. No data, not zero." The image has no `src` then, so no stale frame can show.
- A story with no frames (the fixture) shows "This story has no map images."
- Legend text = story legend + the colour-key range. Region text = box coordinates and grid from `meta.region`.
- "Show data table" is a button with a constant label and `aria-expanded`. The table has a caption, `scope` headers, one row per step, and "No data, not zero" for the gap. The current row has `aria-current`.
- The picture moves when the user moves the slider or when playback stops or pauses. It does not move during Play and never writes to the live region.

**T8: What the sound hides** (`app/sound/plan.js`, `app/sound/engine.js`, `app/player/hides.js`)
- `plan.js`: `hidesPlan`, `hzCoarse`, `hidesFacts`, `hidesExplanation`. The coarse rule is fixed: the story's pitch domain is cut into 3 levels (`HIDES.levels`). The fine version is Side B. Same timing, same click, same silent rest, no new layers.
- `engine.hides("coarse"|"fine")`: a one-shot like the others (pauses live playback, needs a user action first).
- UI: "Play version 1 / 2" (order shuffled each round), a radio group "Which version hides the change?", Reveal, New round.
- The answer stays inside the module until Reveal. The page HTML never contains "coarse" or "fine" before that.
- Reveal text is built only from story numbers. On the Mauritius story: 8 °C range, 3 levels of 2.67 °C, 2 pitches against 19, 16 of 17 neighbouring changes silent in the coarse version, 17 of 17 in the fine one, change of -2.35 °C.
- Listener helper: a log table (round, guess, truth, correct) and a running line "x of y rounds correct. This is a practice log on this page only. It is not a study result." No network, no storage.

## Tests

- New: `app/player/picture.test.mjs` (13), `app/sound/hides.test.mjs` (21), shared `app/player/testkit.mjs`. Both registered in `app/package.json`.
- Whole app suite: **99 pass, 0 fail** (includes the other fork's `qa` tests at the time of the run). Contract 19 pass, pipeline 16 pass.
- Includes axe-core on the page with the table open: no serious or critical issues (colour contrast is not testable in jsdom). Exactly one live region. The app never calls `focus()`.
- A test caught a real bug: the picture did not follow the slider on a second scrub, because it updated only on state changes. Fixed in `player.js` (the slider `input` handler now calls `picture.update`).

## Verified in real Chrome (desktop and a 390×844 mobile emulation; local server, killed afterwards)

- Page loads with no errors (one favicon 404).
- Real key presses and clicks: slider to the gap step shows the panel, no image, the right table row marked, live region empty, focus left on the button the user pressed.
- Real frame for step 1 and the last step; Mauritius shows as the blank land inside the dashed box.
- At 390 px: no horizontal scroll (scroll width = client width); the table is 366 px wide.
- Hides flow: Play version 1 starts the AudioContext (`running`); a guess plus Reveal logs one row and writes one live message.
- Screenshots looked at: desktop gap view (dark mode) and mobile step 1. A second mobile screenshot with the table open timed out; the table fit was measured instead.

## NOT verified

- **Nobody has heard the hides versions.** I do not know that the coarse version actually sounds like it hides the change. It plays 2 pitches over 19 steps, which may still sound like one clear step.
- **The "≥2 of 3" listener test (T0 §A) has not been run.** The helper only makes it possible. Any result from this page would be a practice log.
- No NVDA, TalkBack or VoiceOver pass on the Picture, table or hides sections. The table and the radio group were checked only through the Chrome accessibility tree and axe.
- Light mode and colour contrast were not checked in the browser (only dark mode was seen, plus axe without contrast).
- Safari, iOS and Android not tested.

## Deviations and decisions to review

- The coarse level count (3) is my choice, not tuned. If the red team wants another value, change `HIDES.levels` in `plan.js`; the text and tests follow.
- The explanation's "2.67 °C" and "16 of the 17" are computed in code from story values, not stored in `facts.json`, so they are not in the fact sheet. The code checker `validate_facts.py` does not cover them. A test checks every number comes from `hidesFacts`.
- I added an `rng` parameter to `mountPlayer` (default `Math.random`) so tests can fix the shuffle. Only tests set it.
- The table's Source column shows the source ID (for example MUR), with a line under the table that explains each ID. No `abbr` or scroll container was used because the existing test forbids custom tab order.
- The picture shows nothing new during Play, so a sighted viewer does not see the picture follow the music. That keeps the page quiet but is less lively on stage.
- The hides section's intro states that "one of them hides the change", which is true for any story by construction. For a story whose series is already almost flat, the two versions may sound alike; the explanation numbers would show that honestly.
